Chrome palette from a generated Material scheme

Prototype renders of the real Rex Rune build (prototype branch), headless through Rune's --snap. Each palette is built from a matugen scheme-tonal-spot of a real wallpaper, plus DMS's dank16 for status colours. The panes declare a Ghostty theme from the same scheme. Mappings A, B and C differ in which roles fill the palette slots. Arrow keys cycle the mapping; Up and Down cycle the screen.
